# 06 — 步数与最少步数显示

**What to build:** 游戏进行中随时可见当前步数与当前盘数对应的最少步数,每走一步即时刷新。

**Blocked by:** 02、04

**Status:** resolved

**验收方式:** 真机(或 Apple Silicon 模拟器)运行应用人工观察/交互;引擎侧断言在 Hypium 中。

- [x] 界面显示当前步数,随合法移动递增
- [x] 界面显示最少步数(2ⁿ−1),随开局盘数变化
- [x] 非法移动不改变步数显示
- 实现已提交:步数行(当前步数 + 最少步数)随合法移动与开局盘数刷新;数据全部读自引擎(`moveCount` / `minMoves`),非法移动不触碰。构建 + 9 例测试全绿。待真机人工验收。
